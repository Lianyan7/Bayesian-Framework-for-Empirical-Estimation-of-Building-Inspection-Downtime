# A-Bayesian-Framework-For-the-Empricial-Estimation-of-Inspection-Downtime
Supplemental Materials for the Paper **"A Bayesian framework for the empirical estimation of building inspection downtime following earthquakes".**

This project introduces a probabilistic Bayesian framework for quantifying inspection delays at the individual building level while explicitly accounting for uncertainties in downtime estimates. The code, developed by Lianyan Li, implements the methodologies detailed in the following publication:

Li, L., Chang-Richards, A., et al. (2025). _A Bayesian framework for the empirical estimation of building inspection downtime following earthquakes_.

This repository contains one Python file (Markov Chain Monte Carlo.py) and an Excel document (Summarised statistics of the collected empirical dataset.xlsx) detailing the statistical summary of the collected empirical data.

Contributions, feedback, and suggestions for improvement are most welcome.
